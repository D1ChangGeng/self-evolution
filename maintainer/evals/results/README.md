# Recorded Results

`v2-current.json` and `../RESULTS.md` are generated by:

```text
node maintainer/evals/run.mjs --record
```

They contain stable artifact facts, full fixture-contract digests, and gate
states only. Raw integrated task runs belong in a versioned run directory when
they are executed. Register them through the hashed manifest described in
`../evidence/README.md`; do not add a synthetic pass or infer a blinded wrong-
knowledge or no-Capture result from deterministic probes.
