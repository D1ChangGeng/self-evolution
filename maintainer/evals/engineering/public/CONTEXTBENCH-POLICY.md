# ContextBench continuity policy

Status: `pre-execution contract`. This policy applies to the two frozen public pairs in `CONTINUITY-SOURCES.md`: Astropy `14995 → 15082` and SymPy `19487 → 19484`.

Each pair has two independently materialized task bases. The experience patch is never applied to the related base. The evaluated Codex agent must solve the experience issue afresh in the official experience image. Only after that process has finished may the coordinator create a compact continuation record from the actual Codex attempt: task/base IDs, issue summary, diagnosis, changed paths, test commands and exits, patch hash, and attempt receipt hash. The treatment related task receives that record read-only; the matched B0 control receives no record. Neither receives the experience worktree, patch bytes, gold patch, test patch, packaged `Lite Past Experience` trajectory, or evaluator feedback.

B0, B4, and B5 remain the ordinary formal subjects supplied by the existing public `run_task.py` runner. ContextBench does not create a second agent runtime. Each experience or related task retains the runner's two fresh Codex processes. The related task is evaluated only after both related processes have exited, and no official verifier result can enter a retry prompt.

The public data and evaluator are coordinator-only. `contextbench.py freeze` writes the selected row data and a dispatch manifest. `contextbench.py provision` pins the public evaluator commit and attempts every expected image tag: experience rows use the corresponding official SWE-bench image (`swebench/sweb.eval.x86_64.<owner>_1776_<repo>-<number>:latest`), while related rows use the ContextBench image (`jiayuanz3/swecontextbench:<owner>.<repo>-<number>`). A missing image is recorded as `blocked-missing-official-image`; it must not be replaced with a locally rebuilt image and labeled official. `contextbench.py preflight --kind gold|noop` runs the author-provided `evaluation.sh`; it starts no model and is only a verifier/infrastructure check. A gold preflight may establish that the frozen source/evaluator/image combination accepts its reference patch. A no-op preflight must remain a failed task outcome when the official tests reject it; it is never counted as model performance.

The official evaluator is the acceptance authority for ContextBench `FAIL_TO_PASS` and `PASS_TO_PASS`. Its container result does not establish the project's separate architecture, write authorization, delivery scope, or OS isolation claims. Those remain bound to the existing public engineering runner's snapshots, probe, receipts, and review evidence.

Every executed related task receipt must bind: pair ID, source dataset revision, exact relationship row hash, both task row hashes, evaluator commit/script hash, pulled image digest, continuation hash (or explicit `none` for B0), originating experience attempt-manifest hash for treatment, subject hash, fresh session receipts, model patch hash, and official evaluator receipt. Missing any item leaves the continuity result pending.
